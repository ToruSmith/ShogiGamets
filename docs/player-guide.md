## 安裝到手機或電腦

安裝後會出現在主畫面，打開時沒有網址列；大廳出現「已可離線使用」後，**沒有網路也能玩**（線上對戰除外）。

| 裝置                 | 做法                                                              |
| -------------------- | ----------------------------------------------------------------- |
| iPhone／iPad         | 用 Safari 打開網址 → 點「分享」→「加入主畫面」                    |
| Android              | 用 Chrome 打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」 |
| 電腦（Chrome、Edge） | 網址列右側的「安裝」圖示                                          |

## 遊戲模式

| 模式       | 內容                                                                        |
| ---------- | --------------------------------------------------------------------------- |
| 對電腦     | 入門到全力共八段難度，可以選先手、後手或隨機，也能設定駒落ち與持時間。      |
| 雙人同機   | 一台裝置兩人輪流下，可以悔棋、翻轉棋盤。                                    |
| 線上對戰   | 開房間邀請朋友，或從大廳加入公開房間。見[和朋友線上對戰](#和朋友線上對戰)。 |
| 詰將棋     | 36 題，一手詰到七手詰。主變化以外的正解也算對，看不出來可以要提示或看解答。 |
| 棋譜與復盤 | 下完的對局自動存在這台裝置；可以復盤、賽後分析、匯入匯出 KIF／SFEN。        |

下到一半關掉也沒關係，大廳會出現「繼續上一盤」。

### 電腦的難度

入門、初學、初級、中級、進階、有段、高段、全力。低難度會像人一樣犯錯，但一定看得到一手詰。
覺得太難就往下調，連贏幾盤再往上。

### 駒落ち（讓子）

平手以外，可以選香落ち、右香落ち、角落ち、飛車落ち、飛香落ち、二枚、四枚、六枚、八枚、十枚落ち。
讓子的一方叫「上手」，**由上手先走**；被讓的一方叫「下手」。

## 規則重點

基本走法與一般將棋相同。容易出錯的地方：

- **升變（成り）**：走進、走出或在敵陣（對方那邊的三排）內移動時可以升變，畫面會問「成」或「不成」。
  設定裡可以改成自動升變。
- **二步**：同一直行不能有兩枚自己沒升變的步兵，遊戲不允許這樣打入。
- **打步詰**：不能打入步兵直接將死對方（走步兵將死可以）。
- **行き所のない駒**：之後再也動不了的位置不能放，例如步兵、香車在最後一排，桂馬在最後兩排。
  走到那裡時一定要升變。
- **千日手**：同一局面（含持駒與輪到誰）出現第四次就是和局。
- **連續王手の千日手**：如果千日手是因為一方一直將軍造成的，**將軍的一方判負**。
- **入玉宣言**：採 CSA 規則的 27 點法。條件全部符合時，輪到你的回合會出現「入玉宣言」按鈕：
  - 自己的王在敵陣，而且沒有被將軍。
  - 王以外，在敵陣裡的自己的棋子有 10 枚以上。
  - 敵陣裡的棋子加上持駒的點數：飛車、角行（含升變）各 5 點，其他棋子各 1 點，王不算。
    先手要 28 點以上，後手要 27 點以上。
- **持將棋（提和）**：雙人同機可以當場同意和局；線上要雙方在同一手都按「提和」。對電腦沒有提和。

## 持時間（棋鐘）

| 選項              | 意思                              |
| ----------------- | --------------------------------- |
| 不計時            | 慢慢想。                          |
| 切れ負け 5／10 分 | 每人總共 5 或 10 分鐘，用完就輸。 |
| 30 秒讀           | 每一手都要在 30 秒內走完。        |
| 10 分＋30 秒讀    | 先用掉 10 分鐘，之後每手 30 秒。  |
| 30 分＋60 秒讀    | 先用掉 30 分鐘，之後每手 60 秒。  |
| 3 分＋每手 2 秒   | 費雪制：每走一手加 2 秒。         |
| 10 分＋每手 5 秒  | 費雪制：每走一手加 5 秒。         |

讀秒最後十秒會有提示音。

## 和朋友線上對戰

1. 點「線上對戰」，輸入名字（最多 16 字），選駒落ち、持時間與自己坐先手或後手。
2. 按「開房間」，把 6 個字的房間代碼或邀請連結傳給朋友。
   勾選「公開到大廳」的話，其他人也能從大廳加入。
3. 朋友打開連結（或輸入代碼）就會入座，對局開始。

對局中：

- **斷線或重新整理**：用同一台裝置、同一個瀏覽器回到原本的連結，就會回到同一盤棋。對手離線時畫面會顯示。
- **持時間**由伺服器時間計算，雙方看到的時間一致。對手斷線時，他的時間會繼續走。
- **投了、提和、入玉宣言**都可以用；線上不能悔棋。
- **再戰**：結束後雙方都按「再戰」，會開一盤新的並交換先後手。
- **觀戰**：兩個座位都坐滿後，第三個人打開連結就是觀戰，只能看不能下。

## 復盤與賽後分析

- 對局結束後按「復盤分析」，可以逐手瀏覽，或從任一個局面「從這個局面開始下」。
- 按「開始分析」，電腦會看完每一手，畫出**先手勝率**的形勢圖，以箭頭標出推薦手，
  並把每一手標成最善、好手、緩手、疑問手或惡手，最後統計雙方的惡手、疑問手與緩手。
- 線上對局也能在結束後分析。

## 棋譜（KIF／SFEN）

- 下完的對局會自動存在這台裝置的「棋譜與復盤」。
- **匯出**：下載 `.kif` 檔，或複製 SFEN。
- **匯入**：貼上 KIF 或 SFEN（例如 `position startpos moves 7g7f 3c3d`），或直接選擇 `.kif` 檔。
  一般將棋軟體輸出的 KIF 都讀得懂，包含駒落ち、盤面圖、消費時間與日文編碼（Shift_JIS）；有變化手順時只讀主線。

## 操作與設定

- 走子可以**點選**（先點棋子再點目的地），也可以**拖曳**。打入時先點駒台上的持駒。
- 設定裡可以切換：繁體中文／英文、淺色／深色／跟隨系統、駒音、顯示可走的格子、顯示座標、自動升變、線上顯示名稱。

## 常見問題

**線上對戰一直連不上？**
先確認網路正常，再重新整理頁面。學校或公司網路有時會擋住即時連線，換成手機網路試試看。

**為什麼看到的還是舊版本？**
遊戲會先用裝置上的快取，讓沒有網路時也能開。新版本會在下一次開啟時生效，把分頁或 App 完全關掉再開一次即可。

**為什麼不能打入步兵？**
多半是二步（同一行已經有自己的步兵）或打步詰（這一打會直接將死對方）。

**「入玉宣言」按鈕沒有出現？**
要同時符合[規則重點](#規則重點)列出的所有條件，而且輪到你走、王沒有被將軍。

**棋譜不見了？**
棋譜只存在這台裝置的瀏覽器裡。清除瀏覽資料、使用私密瀏覽，或換一台裝置，都看不到原本的紀錄。
重要的對局可以先下載 KIF 備份。

## 你的資料

- **不需要帳號**。遊戲不收集姓名、電子郵件，也沒有廣告或追蹤程式。
- **線上對戰**時，會用 Firebase 匿名登入取得一組隨機代號，房間裡存的是：名字、這組代號、對局設定、棋步與時間、
  是否在線、投了／提和／入玉宣言／再戰的紀錄。任何拿到房間代碼的人都看得到這些內容，公開房間也會出現在大廳，
  所以名字不要用真實姓名。還沒有對手的房間在你離開時就會刪除；其他房間超過一天後會被清除。
- **設定、棋譜與未下完的棋**只存在你的瀏覽器裡，不會上傳。
